#### 目标一：我们的工作是融入大模型进行角色判断，看看能否提升SLM的结果
1. 基本思路是：对小模型没有把握的结果，让大模型判断是否为正确的角色，对大模型判断正确的结果进行保留。
2. 基本假设：大模型有不错的语言分析能力，能够对角色进行较好识别；
3. 方法：1）对小模型预测结果中边缘概率低的角色让大模型进行判断，然后删除LLM进行判断，然后保留大模型认为正确的数据，看是否能提升SLM的最终效果。2）对小模型识别的候选角色池，LLM进行判断，然后保留大模型认为正确的数据，看是否提升小模型最终效果。
